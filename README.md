# 🤖 AI Personal Assistant (n8n + Streamlit + Gemini)

An AI-powered personal assistant that automates daily tasks like:
- 📅 Calendar management
- 📧 Email handling
- 📝 Notes creation
- ✅ Task tracking
- 💰 Expense management
- 🌐 Web search

Built using:
- Streamlit (Frontend UI)
- n8n (Workflow Automation)
- Google Gemini (LLM)
- Google APIs (Calendar, Gmail, Docs, Sheets)

---

## 🧠 Architecture

User → Streamlit UI → Webhook → n8n → AI Agent → Tools → Response

---

## ⚙️ Features

- Conversational AI Assistant
- Multi-tool agent (calendar, email, tasks, notes, expenses)
- Memory-enabled conversations
- Real-time API integration
- Modular workflow design

---

## 🛠️ Tech Stack

- Python
- Streamlit
- n8n
- Google Gemini API
